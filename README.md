# Jujutsu Kaisen — Guia de Personagens

## Sobre o projeto

O app consome uma API de personagens de Jujutsu Kaisen e apresenta os resultados em uma lista com rolagem vertical.

Cada personagem possui:
- Imagem
- Nome
- Participação (principal ou secundário)
- Quantidade de favoritos

## Tecnologias utilizadas

- React Native
- Expo SDK 58
- JavaScript
- React Native Paper
- Tenrai API

## Funcionalidades

- Consulta de personagens
- Exibição de personagens em cards
- Atualização da lista

## Como executar

1. Instale o Node.js.
2. Clone o repositório.
3. Abra a pasta do projeto no terminal.
4. Instale as dependências:

   npm install

5. Inicie o Expo:

   npx expo start

6. Abra o aplicativo no celular utilizando o Expo Go.
